# 新云算力资金图谱

第六版，2026-10-21 更新。交互式展示 AI 基础设施中的资本方、模型公司、云巨头、新云、机房房东与芯片设备商之间的关系。

包含 189 个主体、634 条生效关系和 210 条更正记录。关系区分金额性质、状态、同一事件、同一项目与来源类型；金额可能属于不同口径，不应直接相加。
